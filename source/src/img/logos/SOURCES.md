## Notes

- **msr.svg**: Commons has no transparent "Microsoft + Research" logo. The candidates were `Microsoft-Research-New-Logo.jpg` and `MSR New Logo.jpg`, which are opaque JPGs, and `Segoe msr logo.png`, which is an old text-only logo, 368 px high, licensed CC BY-SA 3.0. So the file used is the Microsoft corporate logo.
- **imperial.png**: the pre-2024 "Imperial College London" wordmark is still available as an SVG if you want a vector file: https://upload.wikimedia.org/wikipedia/commons/d/de/Imperial_logo.svg (PD-textlogo, 800×220, no viewBox). The current logo is very wide, so it looks heavy at the same height as the others. Consider about 20px high.
- **macau.svg**: the horizontal emblem + trilingual name version exists only as a 589×169 PNG (en.wiki, fair use): https://upload.wikimedia.org/wikipedia/en/5/50/University_of_Macau_Logo.png. That is below the 400 px PNG threshold, so the SVG emblem is used.
- **columbia.svg**: the Commons file `Columbia_University_1754_updated.svg` was rejected. It is a user redraw (CC BY-SA 4.0), not the institution's artwork.
